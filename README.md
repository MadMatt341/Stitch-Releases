# Stitch downloads

Stitch makes one MP4 video from an ordered list of local video files.
The app keeps source files unchanged.

Download [Stitch 0.1.3 beta for Windows x64](https://github.com/MadMatt341/Stitch-Releases/releases/download/v0.1.3-beta/Stitch-v0.1.3-beta-win-x64.zip) (95.7 MB).
Extract the complete ZIP before you start `Stitch.exe`.
Keep its runtime and license folders beside the executable.

The [release page](https://github.com/MadMatt341/Stitch-Releases/releases/tag/v0.1.3-beta) contains matching source archives, runtime records, checksums, and beta limits.
The large FFmpeg source archive is a separate download.
You do not need the source archives to run the app.

The [Stitch source repository](https://github.com/MadMatt341/Stitch) contains the application source, documentation, and issue tracker.
The application code uses MIT.
The separate FFmpeg tools use GPL-3.0-or-later.
Each dependency keeps its license.

The [release reference](https://github.com/MadMatt341/Stitch/blob/main/docs/releases.md) gives the distribution procedure and source requirements.
