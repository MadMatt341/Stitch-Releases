# Stitch downloads

Stitch makes one MP4 video from an ordered list of local video files.
The app keeps source files unchanged.

The [Releases page](https://github.com/MadMatt341/Stitch-Releases/releases) is the download destination for portable Windows x64 packages and corresponding runtime source.
The first portable beta is in preparation.
Before you start `Stitch.exe`, extract the complete portable ZIP.

The [Stitch source repository](https://github.com/MadMatt341/Stitch) contains the application source, documentation, and issue tracker.
The application code uses MIT.
The separate FFmpeg tools use GPL-3.0-or-later.
Each dependency keeps its license.

The [release reference](https://github.com/MadMatt341/Stitch/blob/main/docs/releases.md) gives the full distribution contract and source requirements.
